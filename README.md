# Junhao Shen · 申峻豪

申峻豪的静态学术主页，采用左侧个人资料、右侧章节内容的响应式布局。

## 仓库与隐私

目标仓库：J10veff/J10veff.github.io，必须保持 **Private**。当前不启用 GitHub Pages，也没有自动发布工作流。私有仓库不代表 GitHub Pages 网站私有；未来上线时需另行决定访问权限。页面中的 noindex 仅是搜索引擎提示，不是访问控制。

## 修改与预览

直接用浏览器打开 index.html 即可预览，无需构建。也可在本目录运行 python -m http.server 8000 --bind 127.0.0.1，然后访问 http://127.0.0.1:8000。

- index.html：姓名、简介、教育、科研经历、论文、项目与获奖。
- css/site.css：主页的主样式。
- css/personal.css：照片比例、移动端和打印适配。
- js/main.js：导航定位及论文交互支持。
- img/：本人照片与学校校徽。
